ようびと つきの英単語 19個 一覧

曜日7つと月12個。絵で表しにくいので、例文で覚えるのがおすすめです。

カタカナの読み方つきなので、おうちの方が声に出して読んであげられます。この一覧の単語は、そのままえいご シールクイズで音声つきの4択クイズとして練習できます。読み上げを聞きながら遊べるので、英語の文字が読めない年齢でも取り組めます。

例文で覚える

  • Monday … Today is Monday. きょうは げつようび
  • Tuesday … Today is Tuesday. きょうは かようび
  • Wednesday … Today is Wednesday. きょうは すいようび
  • Thursday … Today is Thursday. きょうは もくようび
  • Friday … Today is Friday. きょうは きんようび
  • Saturday … Today is Saturday. きょうは どようび
  • Sunday … Today is Sunday. きょうは にちようび
  • January … It is January. いまは いちがつ

おうちでの覚え方

いちどに全部は覚えられません。1日5〜10個を目安に、声に出して読むところから始めるのがおすすめです。上の表を見ながら親子で言い合って、そのあとクイズで確認すると定着しやすくなります。
